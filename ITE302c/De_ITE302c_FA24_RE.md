### **Câu 1 (ITE302c_-_FA_2024_-_RE_3178.webp)**
**Câu hỏi:**  
You have a dataset of customers that includes each customer's gender, location, and other personal attributes. What type of machine learning outcome is this problem suited for?

**Danh sách đáp án:**

### **Câu 7 (ITE302c_-_FA_2024_-_RE_3178 (6).webp)**
**Câu hỏi:**  
If a coin is flipped, which of the following would ensure "yes/no" data is private while still remaining useful?

**Danh sách đáp án:**  
- A. heads for yes, tails for no  
- B. heads for fake answer, tails for true answer  
- C. heads for true answer, tails for random answer  
- D. heads for random answer, tails for yes  

**Đáp án đúng:** **C. heads for true answer, tails for random answer**  
**Thuộc kiến thức:** *Differential Privacy: Randomized Response Mechanism (Cơ chế phản hồi ngẫu nhiên)*  
**Giải thích:**  
Phương pháp *Randomized Response* (cơ sở của Local Differential Privacy) dùng việc tung đồng xu: nếu mặt Ngửa (Heads) thì trả lời thật (*true answer*), nếu mặt Sấp (Tails) thì trả lời ngẫu nhiên (*random answer*). Cơ chế này tạo ra khả năng phủ nhận hợp lý (*plausible deniability*) giúp bảo vệ quyền riêng tư cá nhân mà thống kê tổng thể vẫn chính xác.
