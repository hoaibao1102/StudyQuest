### **Câu 1 (1.webp)**
**Câu hỏi:**  
What is the primary advantage of radioactive data tracing over past techniques that modify input in order to determine whether or not that input was used in training?

**Danh sách đáp án:**  
- A. Radioactive data tracing can be used to modify the label.  
- B. Radioactive data tracing doesn't impact a model's performance.  
- C. Radioactive data tracing targets language-based input.  
- D. Radioactive data tracing makes the modification perceptible to human beings.  

**Đáp án đúng:** **B. Radioactive data tracing doesn't impact a model's performance.**  
**Thuộc kiến thức:** *Data Provenance & Radioactive Data Tracing (Truy vết xuất xứ dữ liệu bằng dấu vết phóng xạ)*  
**Giải thích:**  
Kỹ thuật đóng dấu phóng xạ dữ liệu (*Radioactive data tracing*) cho phép chèn các tín hiệu ẩn siêu nhỏ vào tập dữ liệu mà không làm suy giảm độ chính xác hoặc ảnh hưởng đến hiệu năng hoạt động của mô hình máy học (*doesn't impact a model's performance*), giúp phát hiện việc sử dụng trái phép dữ liệu để huấn luyện mô hình.

### **Câu 14 (14.webp)**
**Câu hỏi:**  
If a coin is flipped, which of the following would ensure "yes/no" data is private while still remaining useful?

**Danh sách đáp án:**  
- A. heads for yes, tails for no  
- B. heads for fake answer, tails for true answer  
- C. heads for true answer, tails for random answer  
- D. heads for random answer, tails for yes  

**Đáp án đúng:** **C. heads for true answer, tails for random answer**
